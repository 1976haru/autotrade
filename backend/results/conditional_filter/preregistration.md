## SKIP 판정 기준 (셋 중 하나라도 해당하면 그날 = SKIP)

| 조건 | 기준 | 데이터 소스 |
|---|---|---|
| **① SP500 전일 종가 수익률** | ≤ **−1.5%** | yfinance `^GSPC` 일봉 close-to-close |
| **② 코스피 시가 갭다운** | ≤ **−1.0%** (전일 종가 대비) | yfinance `^KS11` open vs prev close |
| **③ 코스피 전일 종가 < 20일 이동평균** | 기술적 하락 | KS11 close 20-day SMA (전일 종가 포함) |

- 셋 중 **하나라도** 해당 → 그날 = **SKIP** (봇은 평소대로 거래, shadow만 기록)
- **임계값 고정** (−1.5% / −1.0% / 20일선): 이 문서 작성 시점 이후 변경 불가
- 판정 기준 시각: 한국 개장 전 (09:00 KST 이전) 전일 데이터 기준

## 분석 단위

- **시간대 구분**: 진입 09:00~09:30 KST vs 09:30 이후
- **평가 지표**: 체결 BUY당 round-trip net 수익률 (FIFO 매칭, avg_fill_price 기준)
- **세션 성과**: 일별 체결 거래 전체 가중 net_ret

## 판정 기준 (4~6주 후)

- **필터 채택**: SKIP일 세션 성과가 TRADE일보다 **유의하게 나쁜** 경우 (최소 10세션 확보 후 비교)
- **필터 기각**: 차이 없거나 반전인 경우
- **주의**: 표본 소규모일 때는 방향성 신호로만 참조, 결론 보류

## 개장 전 "가설"

- 조건 ①②③ 중 하나라도 트리거 → 시장이 불리 → 당일 단타 성과 하락
- 특히 개장 직후 (09:00~09:30) 매수는 ①②③ 트리거일에 더 불리할 것
- → **검증 포인트**: SKIP일의 09:00~09:30 진입 수익률이 TRADE일보다 나쁜가
