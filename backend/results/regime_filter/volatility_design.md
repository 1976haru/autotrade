# 레짐 필터 검증 2 — 변동성 필터 설계 + 데이터 확인 (read-only)

> 작성 2026-07-01. **read-only 연구 — 봇·보호계층 0 변경, 주문 0.** 가설: "전일 시장
> 변동성이 높으면 그날 단타를 쉬는 게 매일 거래보다 낫다." (추세필터 검증1의 후속.)

---

## 0. 결론 먼저

- **데이터 gap: 추세보다 나음 — 검증 가능.** 변동성은 상승장에도 높은 날이 있어, 단타
  데이터 창(2025-05~2026-05)에 **고변동성 날 97일(38%)** 존재(추세필터는 down-regime 0일이라
  막혔음). → 변동성 필터는 발동일 충분, 프록시/실데이터 둘 다 테스트 가능.
- **그러나 결과는 추세와 동일 — 가설 반증.** 일봉 open→close 프록시(2015-2026)에서 **고변동성
  날이 오히려 가장 덜 나빴다**(Q4 −0.003% vs Q1 −0.094%). 필터가 좋은(덜 나쁜) 날을 껐다.
- **★비용벽 못 넘음**: 필터 on/off 둘 다 −100%(비용 지배). 비용0에서도 −72~74%. **레짐필터가
  단타의 구조적 손실(엣지 없음+비용)을 구제하지 못한다.**
- **단서(추세와 다른 점)**: EW-전종목 프록시는 *선별* 단타의 whipsaw를 못 잡는다. 변동성은
  선별전략(모멘텀/돌파)에 직접 영향(고변동=휘프소) → **선별-실intraday 테스트는 변동성에선
  진짜 의미 있음**(데이터도 있음). 프록시 반증이 선별전략까지 배제하진 않음.

## 1. 데이터 gap 확인 (추세에서 배운 것)

| 재료 | 상태 | 비고 |
|---|---|---|
| **변동성 신호** | ✅ KS11 파생 | VKOSPI ❌(파일 없음) → **KS11 trailing-20d 실현변동성**(전일까지). median 1.10%, p75 1.69%. |
| **★단타 창 발동일** | ✅ **97일(38%)** | 2025-05~2026-05 251일 중 고변동성(상위25%) 97일. **추세필터(0일)와 결정적 대조 — 변동성은 상승장에도 발동.** |
| **단타 일별 P&L** | △ 프록시 | 실 단타 일별수익 시리즈 없음(추세와 동일 gap). 일봉 open→close 프록시(2015-2026) 사용. **단, 변동성은 실 intraday(2025-26)로도 테스트 가능**(97 고변동일). |

## 2. 사전등록 (백테스트 전 고정, cherry-pick 금지)

- **신호**: KS11 **trailing-20d 실현변동성**(일간 로그수익 표준편차), **전일까지** 계산(당일
  시작 전 판단 = look-ahead 0).
- **★임계 고정**: 2015-2026 표본 **상위 25%(top quartile) = 고변동성** → 그날 skip. 이후
  "상위 10%가 낫네" 식 튜닝·cherry-pick **금지**. (표본내 분위 사용은 first-pass 단순화 —
  엄밀판은 expanding-percentile.)
- **규칙**: 고변동성 → skip(거래 0, 비용 0). 아니면 거래.
- **지표**: 누적수익, MDD, 거래일수, 비용절감. **승률·일일손익 아님.**
- **대조**: on vs off(매일). **비용**: 왕복 0.35%/일.
- **핵심 진단**: vol 사분위별 프록시 수익 → "고변동성 날이 실제 나빴나".

## 4. ★기대치 관리 — 비용벽을 넘게 해주나?

**아니오.** 단타 자체가 −100%(비용) / −72~74%(비용전 엣지부재). **레짐필터(추세·변동성)는
비용벽을 넘게 해주지 못한다.** 문제는 *레짐*이 아니라 *엣지 없음 + 비용*
([[churn-diagnosis-structural-verdict]]·[[spark-test-feature-ic]]와 정합). 필터로 나쁜 날을
골라 빼도, 남은 날의 기대수익이 여전히 음(-)이라 비용을 못 이긴다.

### 프록시 한계 + 다음 (변동성은 추세보다 후속가치 있음)
- EW-전종목 ≠ *선별* 단타. **변동성은 선별전략에 직접 영향**(고변동=whipsaw로 진입신호
  거짓양성↑) → EW 프록시가 못 잡는 효과. **여기선 실 intraday(2025-26, 97 고변동일) 로
  선별-모멘텀 전략의 일별 P&L을 vol split 하는 테스트가 진짜 의미 있다**(추세와 달리 데이터 있음).
- 즉 **프록시는 (b)/(c)지만, "선별전략 + 실 intraday" 재검증은 변동성에 한해 정당**. 이게
  다음 단계 1순위.
