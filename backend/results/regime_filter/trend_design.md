# 레짐 필터 검증 1 — 추세 필터(200일 MA) 설계 + 데이터 확인 (read-only)

> 작성 2026-07-01. **read-only 연구 — 봇·보호계층 0 변경, 주문 0.** 가설: "코스피가
> 200일 MA 아래인 날 단타를 쉬면, 매일 거래보다 순성과가 낫다."

---

## 0. 결론 먼저 (정직한 데이터 gap)

- **200MA 신호**: ✅ 완비 (KS11 일봉 1996~2026, 40%가 MA 아래 — 30년 레짐 풍부).
- **단타 일별 P&L(핵심 재료)**: ❌ **필터 검증에 치명적 gap.** intraday(단타) 코퍼스는
  **2025-05~2026-05 ~1년뿐**인데, **그 창에서 코스피가 200MA 아래인 날 = 0일(0%)** —
  완전 상승장이라 **필터가 발동할 down-regime 날이 아예 없다 → 단타 실데이터로 검증 불가**.
- 필터가 의미 있는 하락장(2022 100%·2018-19 73%·2015-16 42%·2020 25%)엔 **intraday 데이터가
  없고 일봉만** 있다.
- → **정직한 답: 진짜 "단타 필터" 검증은 현 데이터로 불가.** 가능한 건 **일봉 open→close
  프록시(2015-2026)** 로 필터 *개념* 을 테스트하는 것뿐이며, first-pass 결과는 가설을
  **오히려 반증**한다(아래 §3).

## 1. 데이터 확인 (뭐가 있고 없나)

| 재료 | 상태 | 위치 / 범위 |
|---|---|---|

| **단타 intraday 코퍼스** | △ ~1년 | `intraday_30m_resampled`(35종목)/`5m`(46종목), **2025-05~2026-05**. |

### ★핵심 gap
단타 필터를 제대로 검증하려면 **"각 날짜에 단타전략이 얼마 벌었나(비용후)"** 가 down-regime
기간에 필요하다. 그런데 **intraday 데이터(2025-26)엔 down-regime 날이 0** 이고, down-regime
기간(2015-22)엔 **일봉밖에** 없다. 이 둘의 불일치가 근본 gap.

## 2. 사전등록 (백테스트 전 고정 — cherry-pick 금지)

- **신호**: 코스피 종가 vs 200일 SMA. **전일 기준**(당일 시작 전 판단 = look-ahead 0).
- **규칙**: 전일 종가 < 200MA → 그날 **skip**(거래 0, 비용 0). ≥ → 거래.
- **임계 고정**: **200일**. 이후 "150일이 낫네" 식 튜닝·cherry-pick **금지**.
- **기간**: 데이터 있는 전체. (프록시=2015~2026; 진짜 단타=불가.)
- **평가지표**: 누적수익, MDD, 거래일수, 비용절감. **승률·일일손익 아님.**
- **대조**: 필터 ON vs OFF(매일 거래).
- **비용**: 한국 단타 왕복 **0.35%**(0.3~0.4% 범위 중앙).
- **좋은날 놓침 측정**: 필터가 제외한 날들의 실제 수익(제외가 옳았나 vs 좋은날도 껐나).

## 3. First-pass 백테스트 (프록시 — 일봉 open→close, 사전등록대로)

**프록시 정의**: 단타 ≈ *당일 시가 매수 → 종가 청산*(오버나이트 0). KR 일봉 코퍼스
500종목 EW 평균 open→close 수익을 "그날 단타 수익"의 대리로 사용. 비용 0.35%/일.

### 결과 (2015-01~2026-05, 2,795일)
| | 아래-MA 날 | 위-MA 날 |
|---|---|---|
| intraday EW open→close(비용 전) | **+0.019%** (1,168일) | **−0.088%** (1,627일) |

| | 누적수익 | MDD | 거래일 |
|---|---|---|---|
| 필터 OFF(매일) | −100.0% | −100.0% | 2,795 |
| 필터 ON(위-MA만) | −99.9% | −99.9% | 1,627 (1,168일 skip) |

### 판정: **(c) 악화 방향 / (b) 무의미**
1. **가설 반증**: 하락장(아래-MA) 날의 intraday 수익이 **오히려 +0.019%로 상승장 날(−0.088%)보다
   좋았다.** "아래-MA 날이 단타에 나쁘다"는 전제가 이 프록시에선 성립 안 함 → **필터가 좋은
   날(아래-MA)을 껐다.** 필터가 걸러낸 1,168일이 실제로는 *덜 나빴던* 날들.
2. **비용 지배**: 매일 EW 전체를 왕복 0.35% 로 돌리면 필터 무관 −100%. [[churn-diagnosis-structural-verdict]]
   ·[[timeframe-sweep-deferred]] 의 "비용>엣지, 5분 단타 구조적 손실"과 정합.
3. 즉 **200MA 추세필터는 이 프록시에서 순성과를 개선하지 않는다**(오히려 반대·무의미).

### ★프록시 한계 (과신 금지)
- EW-전종목 open→close ≠ 실제 단타(모멘텀/ORB *선별* 매매). 선별 전략은 레짐 의존이 다를 수 있음.
- open→close는 intraday 드리프트일 뿐 단타 알파 아님.
- −100%는 "매일 전종목 왕복" 프록시의 비용 아티팩트(실 단타는 소수 종목만).
- **그러나 레짐 split(아래+0.019 vs 위−0.088)은 선별과 무관한 시장 사실** — 필터의 대전제가
  최소한 *자명하지 않음* 을 보여줌.

## 4. 안 되면 뭐가 더 필요한가

진짜 "단타 200MA 필터" 검증을 위해 필요한 것(우선순위):
1. **down-regime 기간의 intraday 데이터** — 2018-19/2020/2022 중 최소 한 구간의 분봉(5/30m).
   KIS 분봉은 depth 얕음(모의 ~30일) → pykrx/유료 분봉 수집 or forward-collect 필요.
2. **선별 단타전략의 일별 P&L 시리즈** — 기존 백테스트 엔진이 *날짜별 net 수익* 을 emit 하도록
   1회 실행(집계 아닌 equity_curve 출력). down-regime intraday 확보가 선결.
3. (차선) **선별 프록시**: 일봉으로 top-모멘텀 decile open→close + 200MA split — EW보다 단타에
   가깝게. 단 사전등록·단일실행으로 cherry-pick 회피.

**권고**: 현 데이터로는 (b)/(c) 이상 결론 불가. down-regime intraday 없이는 "단타 필터 유효"를
주장할 근거가 없다. 다음 단계는 **선별-프록시(위 3번)** 로 한 번 더 확인하거나, intraday
down-regime 데이터 수집 여부를 결정하는 것.
